How a scan cycle works

A scope groups the Internet-facing IP addresses, hostnames and web application URLs that make up one cardholder data environment.

  1. Define the scopeList the IP addresses, hostnames, ranges and web application URLs to test.
  2. Authorize and scanConfirm you may test the targets, then run ports, TLS, web application and known-vulnerability checks.
  3. Review the findingsEach result is scored with CVSS and the automatic-failure rules, mapped to PCI DSS requirements.
  4. Declare and disputeDecide on discovered components, declare special notes and dispute false positives with evidence.
  5. Fix and rescanRescan only what failed and combine the results into one status for the period.
  6. ReportAttest and export the report as HTML, PDF, JSON, CSV or Markdown.
