Import results

Score results from another scanner with the ASV policy, special-note rules and PCI DSS mapping, then dispute and report them here.

Supported formats

  • Tenable Nessus: .nessus (v2) export, including Nessus Essentials.
  • Greenbone / OpenVAS: XML report export.
  • OWASP ZAP: traditional JSON report.
  • Nuclei: -jsonl output.
  • Nmap: -oX output.
  • testssl.sh: --jsonfile output.

Hosts in the file are added to the scope. Card numbers found in evidence are masked on import.
